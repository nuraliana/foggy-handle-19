# Candidate Usernames

## How the entries are judged

Two names go head to head and the judge picks the one that feels funnier or more interesting. The deciding factor is ownership: the name has to actually belong to the person entering it. A made-up word can sound clever, but it falls behind a genuine handle because it is not really theirs.

## The shortlist

### 1. nuraliana-ana — 5/5

This is Nur's own handle on the platform, so it clears the ownership test outright and stays memorable without trying too hard.

### 2. A shortened form of the handle — 3/5

Cutting the handle down keeps a link to the real account, yet it drops part of the identity and reads plainer than the full version.

### 3. A coined funny word — 2/5

A fresh invented word can raise a smile on its own, but it is not Nur's handle, so it loses the contest's core point and would fall to any genuine entry.

### 4. A multi-word phrase — 1/5

A phrase stretches past what a username is meant to be, and it is neither Nur's handle nor a single name, so it scores lowest on both fit and ownership.

## Pick

Enter `nuraliana-ana`. It is the only option that is both the real account name and a distinctive entry, which is exactly what the judge rewards.
